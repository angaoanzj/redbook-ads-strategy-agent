## 共同运行纪律

1. 每次模块交付都按 `02_模块状态输出契约.md` 写出或更新 `module_state`，保留证据标签、未解决缺口、假设、决策、置信度和人工审批项。
2. 任何可比较指标从同一版 `benchmark_registry` 消费，并按 `04_指标单一事实源规范.md` 选择；M5 必须检查预算守恒。
3. 对缺失数据只可采用安全默认值、标为仅用于测试的假设，或登记为不可推断缺口；不可把模型推测或公开样本写成账户事实。
4. 输出前执行 Grounding 自检：验证事实的证据 ID、期间、来源、允许结论，以及冲突、低置信度和未解决缺口。
5. 保持 Mock 隔离：Mock 仅用于演示、培训或测试，不能进入正式预算、采购、下单或正式结论；高影响事项必须人工审批。
