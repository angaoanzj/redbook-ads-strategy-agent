# 曲奇四重奏小红书数据分析报告

生成日期：2026-07-24

本报告使用已安装的 `data-analytics`、`competitor-analysis`、`content-performance-analysis`、`traffic-analysis`、`roi-analysis` 和 `data-report` 方法整理。只使用本地知识库中的真实用户导入/公开观测数据，不使用已删除的 Mock 数据。

## 一、数据范围与可信度

### 真实数据

- 投放月报：2025-06 至 2026-05，来源为用户提供的《数据需求.xlsx》；平台导出来源仍需业务方确认。
- 内容聚合：2026-01 至 2026-05，来源为同一工作簿；只有月度聚合，不是逐笔内容明细。
- 公开笔记：知识库共 205 条；其中按“蝴蝶酥 / 曲奇四重奏 / 香港伴手礼”检索命中 122 条，来源标记为“小红书登录后公开搜索页面（个人研究样本）”，证据等级 `B_public_observation`。

### 当前不能推出的结论

- 不能把搜索样本当成全平台大盘。
- 不能根据公开笔记反推竞品聚光账户真实预算、真实定向和投放时长。
- 不能根据投放消费和互动推导成交订单、ROAS 或真实成交成本；工作簿没有归因订单和成交额。
- 月度内容数据没有逐篇 URL、发布时间、内容类型和账号维度，因此不能做真实的逐篇爆款聚类。

## 二、投放流量与 ROI 代理分析

### 2026 年 1—5 月投放汇总

| 指标 | 结果 |
|---|---:|
| 消费 | 约 577.65 万 |
| 曝光量 | 约 1.198 亿 |
| 点击量 | 约 1922.16 万 |
| 加权 CTR | 16.05% |
| 加权 CPC | 0.301 |
| 加权 CPM | 48.22 |
| 总互动量 | 约 199.49 万 |
| 平均互动成本 | 2.90 |

### 关键变化

1. 2 月 CPC 最高（0.320），4 月最低（0.223）；成本并非随曝光量单向变化，说明月份、素材或流量结构需要拆分验证。
2. 搜索组件点击转化率从 1 月 0.77% 降至 5 月 0.34%，搜索效率明显走弱；不能继续只扩大预算，应拆分品牌词、品类词、购买渠道词并分别观察。
3. 4—5 月互动成本升至 5.82 左右，而 3 月为 1.77；建议把互动成本异常作为素材/人群/流量切换的诊断触发器。
4. 当前只能做“互动效率”和“搜索组件效率”分析，不能称作真实 ROI。需要补充订单、成交额、退款和归因窗口后，才可计算 ROAS、CPA、CAC 和利润 ROI。

## 三、内容与竞品样本分析

知识库 205 条公开笔记中，检索相关词命中 122 条。当前样本呈现的高频需求方向包括：

- 香港伴手礼和香港手信
- 蝴蝶酥购买攻略、试吃和横评
- 曲奇礼盒、包装和送礼场景
- 口味、配料、酥脆度和保质期
- 内地购买、机场购买和正品/渠道问题

### 目前可落地的内容机会

1. “购买决策”比单纯产品展示更适合做搜索承接：机场怎么买、内地怎么买、送长辈怎么选、原味与杂锦怎么选。
2. “横评/实测”是明显的比较型内容方向，但品牌应只基于真实试吃和可核验证据，不虚构竞品结论。
3. “包装 + 场景 + 口味选择”适合礼盒转化；需要逐篇收藏和评论数据验证哪一种场景最能带来购买意向。
4. “品牌故事/谢宁”适合做认知入口，但不能直接等同于成交，需要和产品证据、购买路径、礼赠场景绑定。

### 当前样本缺口

- 公开样本字段有标题、互动和 URL，但没有可靠的账号粉丝快照、评论原文全量、投放持续时间和广告后台数据。
- 因缺少统一发布时间与完整逐篇曝光量，暂不输出“平台流量高峰时段”结论。

## 四、对当前 Agent 的直接改进建议

### P0：先建立数据质量门槛

- 每个模块输出 `source_type`、`evidence_grade`、`sample_size`、`as_of` 和 `is_mock`。
- 未提供订单/成交额时，禁止输出 ROAS、真实 CPA 和“预计成交额”。
- 未提供逐篇发布时间时，禁止输出真实发布时间高峰。
- 未提供广告标识或后台记录时，竞品投流只能输出“待人工核验”。

### P1：把模块1/3/6拆开

- 模块1：市场与竞品内容证据，回答“对手内容做了什么”。
- 模块3：关键词和达人，只有导入真实达人数据时才输出推荐名单；否则输出筛选条件和待采集字段。
- 模块6：关键词分层、搜索词表现和热搜监测，避免重复生成模块3的字符串词库。

### P1：聚光前置决策改成测试设计

在缺少成交归因时，不给假 ROI，而是输出：

- 测试单元：素材 × 词包 × 人群 × 搜推位
- 最小测试预算
- 观察窗口
- 停止条件：CPC、CTR、搜索组件转化率、互动成本
- 放量条件和回滚动作

## 五、下一步数据接入清单

1. 聚光账户逐计划报表：计划 ID、目标、开始/结束时间、花费、曝光、点击、转化、成交额、素材 ID、人群包。
2. 小红书逐篇内容导出：URL、发布时间、曝光、阅读、点赞、收藏、评论、分享、涨粉、内容类型、广告标识。
3. 生意归因表：订单 ID、商品、金额、来源计划、来源笔记、归因窗口、退款状态。
4. 达人/蒲公英数据：账号、粉丝、受众画像、报价、历史合作效果。
5. 拒审/限流台账：日期、内容、违规原因、平台处置、申诉结果。
