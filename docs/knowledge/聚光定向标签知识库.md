# 聚光定向标签知识库

## 这份库是什么

整理公开渠道对小红书聚光「高级定向」体系的说明，并按品类生成**待后台核验**的：

- 人口 / 行为 / 心理画像维度
- 兴趣标签候选
- 行为标签候选
- 人群包候选

源文件：`examples/knowledge/juguang_targeting_catalog.json`  
证据等级：`C_public_secondary_synthesis`（公开二级信源整理 + 品类候选）

## 重要边界

- **不是**聚光后台完整叶子标签导出（平台不公开全量 API 清单）。
- **不能**替代账户创编页搜索核验。
- 模块2 会把它当候选写入画像/标签；`tag_status` 仍必须写「标签需在聚光后台核对可用性」。

## 导入

```bash
cd xiaohongshu-strategy-agent
python knowledge_base.py import-targeting examples/knowledge/juguang_targeting_catalog.json
python knowledge_base.py status
```

## 查询

```bash
# HTTP（服务启动后）
curl 'http://127.0.0.1:8000/knowledge/targeting?category=香港蝴蝶酥伴手礼&audience=到港游客送礼&selling_points=伴手礼,牛油'
```

分析时打开 `use_knowledge=true`，会自动把匹配剧本摘要写入 `targeting_knowledge_brief`，供模块2 使用。

## 已覆盖品类剧本

| playbook_id | 适用 |
| --- | --- |
| `hk_bakery_souvenir` | 香港烘焙伴手礼 / 曲奇蝴蝶酥 |
| `gift_food_general` | 礼赠食品 / 节促零食 |
| `travel_outbound_city` | 出行旅游 / 目的地种草 |
| `beauty_care` | 美妆个护 |

## 后台落地清单（通用）

1. 聚光 → 新建计划 → 高级定向 → 行业兴趣：搜一级类目（如食品饮料、出行旅游）。
2. 关键词兴趣 / 关键词行为：用剧本里的词试覆盖人数。
3. 人群包定向：平台精选（行业 / 生活方式 / 节促）+ 自定义转化包。
4. 不可用标签：换同义类目或改关键词行为；不要硬写进账户事实。
