# 曲奇四重奏数据产出与知识库整理记录

更新时间：2026-07-24

## 1. 真实数据来源与整理方式

### 1.1 用户提供的 Excel

来源文件：`数据需求.xlsx`

包含三个工作表：

- `产品信息`：5 个产品的名称、价格、核心卖点和目标人群。
- `投流数据`：2025 年 6 月至 2026 年 5 月的月度消费、曝光、点击、CTR、CPC、CPM、互动、搜索组件等字段。
- `内容数据`：2026 年 1 月至 5 月的月度篇数、曝光、点击、点赞、收藏、评论聚合数据。

整理方式：

1. 保留原始字段和原始数值，不用模拟值覆盖。
2. 将产品记录写入 `brand_products`。
3. 将月度投放记录写入 `paid_metrics`。
4. 将月度内容聚合记录写入 `organic_metrics`。
5. 在 `brand_profiles` 中保存品牌档案、原始文件名、采集时间和证据等级。
6. 原始工作簿没有提供平台导出来源、URL、账号、评论原文或广告素材，因此不推断这些字段。

证据等级：`C_user_provided_workbook`。

### 1.2 公开网页核验数据

主要来源：

- 官方关于我们页面：<https://twdev.cookies-quartet.com/about-us>
- 香港品牌发展局：<https://www.hkbrand.org/sc/gallery/1/brand/307?activePage=8&page=3>
- MOKO 新世纪广场门店页面：<https://www.moko.com.hk/zh-hans/dinings/cookies-quartet/>

整理出的字段：成立年份、创办人信息、公开门店区域、主要产品、公开奖项、官网及社交平台入口。

整理方式：保存为 `quartet_public_sources.json`，并将已核验的品牌档案更新到 `brand_profiles`。

证据等级：`A_public_official_sources`。

公开资料中的“累计销售超过 2 亿件”等宣传口径保留来源说明，不当作独立审计后的经营数据。

## 2. 已删除的模拟数据记录

此前生成的 8 条模拟内容笔记、5 个月模拟生意数据和 4 条品牌投放明细已按需求删除，相关 JSON 文件、生成脚本、SQLite 模拟表和来源登记均已清理。

当前尚未生成新的模拟数据。后续如需模拟，将只针对“竞品聚光账户数据”单独建模，并使用独立的 `MOCK_COMPETITOR_SPOTLIGHT` 证据等级。

## 3. 检索和使用边界

默认分析应优先使用真实数据；未来的竞品聚光模拟数据只能用于：

- 开发和测试检索功能
- 测试报告生成和指标计算
- 测试前端展示和 Agent 工作流
- 在真实数据缺失时演示输出结构

对外报告、实际投放预算、财务判断和品牌宣传不得把 `MOCK_SYNTHETIC` 数据当作真实事实。
