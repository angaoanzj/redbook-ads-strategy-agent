# 可复现随机 Mock 全量补全设计

## 目标

当分析所需字段没有真实样本或可核验公开资料时，系统生成一套完整、内部一致且可复现的随机模拟数据。用户可以通过“换一组 Mock”按钮生成新方案；所有模拟字段必须醒目标识，不能与真实事实混淆。

## 随机种子

- `/analyze` 增加可选查询参数 `mock_seed`。
- 传入种子时，同一请求、同一种子必须生成完全相同的 Mock。
- 未传种子且 `allow_mock=true` 时，后端生成新的安全随机种子并写入响应追踪信息。
- 前端首次分析生成一个种子并显示；“换一组 Mock”生成新种子后重新提交当前表单。
- JSON 和 Markdown 导出均保存种子，便于复现实验结果。

## 数据优先级

字段级优先级保持：

1. 品牌授权或用户导入的真实数据。
2. 可核验公开资料。
3. 模拟数据（Mock）。

Mock 只能填补缺失字段，不得覆盖真实值。真实搜索笔记的趋势与模拟平台大盘必须分栏展示。

## 随机生成范围

### 自然流量

- 保留“搜索样本自然流量分析”，明确它不是平台大盘。
- 新增“模拟平台自然流量大盘”：最近 30 天每日发布量、互动量、互动率、峰值日期、发布时间高峰、标签和内容形式。
- 生成的日序列需体现基础趋势、周末效应和有限随机波动，所有数值非负。

### 聚光投放

- CPC、CPM、CTR、转化率、转化成本、CPE。
- 种草／成交／客资目标热度排序。
- 搜索与信息流预算占比，两者之和必须为 100%。
- 搜索与信息流各自的低／中／高出价情景。
- “流量方向”只能表述为模拟测试方向，不能声称为 2026 平台真实倾斜。

### 竞品拆解

- 生成 3–5 个匿名模拟竞品，名称使用“模拟竞品 A”等，不冒用真实品牌。
- 为每个模拟竞品生成内容形式、互动量、广告标识情景、投放时长、预算区间和受众假设。
- 预算下限小于中位数，中位数小于上限；投放时长为正整数。
- 生成爆款共性、内容空白和建议动作，但结论语气必须使用“模拟情景”“待验证”。

### 风险预警

- 官方规则继续使用真实公开规则，不随机生成法规条文。
- 缺少账户处罚台账时，生成“模拟风险台账”：风险类型、模拟发生次数、模拟拒审次数和处置建议。
- 不得将模拟频次称为赛道真实高频或平台处罚统计。

### 达人和关键词

- 达人证据不足时生成 20 位匿名模拟达人，覆盖素人、达人、KOL。
- 随机生成粉丝量、平均互动、报价、匹配度和历史投流演示指标，并保持分层范围合理。
- 趋势词不足时生成模拟关键词、热度、竞争度、意向等级和风险分。
- 模拟达人不得使用真实账号链接或声称真实合作历史。

## 数值一致性约束

- 所有金额、比例、互动和人数必须非负。
- CPC、CPM、CTR、CVR、CPA 之间保持基本一致：`CPA ≈ CPC / CVR`，允许小幅模拟噪声。
- 搜索占比与信息流占比之和为 `1.0`。
- 低位值 `<` 中位值 `<` 高位值。
- 达人平均互动不得大于粉丝数；报价随达人层级整体递增。
- 汇总值必须由明细重新计算，不得分别随机造成矛盾。

## Mock 元数据

每个模拟对象必须包含：

```json
{
  "data_type": "模拟数据（Mock）",
  "is_mock": true,
  "evidence_grade": "M",
  "source_name": "系统可复现随机模拟",
  "mock_seed": "本次种子",
  "mock_basis": "随机范围与计算关系说明",
  "warning": "仅用于方案演示和敏感性分析，不代表真实平台、竞品或账户数据。"
}
```

前端在模块标题、对象、表格行及导出报告中显示橙色 `模拟数据（Mock）` 标签，并在报告顶部显示本次种子。

## 页面交互

- 保留“允许使用明确标识的模拟数据补足缺失指标”开关。
- 增加只读的“当前 Mock 种子”。
- 增加“换一组 Mock”按钮；点击后更新种子并重新运行当前分析。
- 关闭 Mock 时隐藏换一组按钮，缺失字段恢复为数据缺口。
- 页面刷新后，已生成报告中的种子仍可从结果区复制，但不自动重新请求。

## 错误处理

- 非法种子统一转换为安全字符串，不执行代码或路径操作。
- 随机生成器只使用本地标准库，不访问网络。
- 任一生成器失败时仅对应模块退化为数据缺口，真实模块继续输出。
- 不因 Mock 存在而提高整体数据可信度等级。

## 测试与验收

- 同请求和同种子产生完全相同的 Mock JSON。
- 更换种子后至少一个 Mock 数值发生变化。
- 真实指标存在时不被 Mock 覆盖。
- 所有随机约束均成立，Mock 对象元数据完整。
- 关闭 Mock 后不生成模拟达人、竞品、趋势、聚光或风险频次。
- 页面按钮能更换种子并重新提交。
- JSON、Markdown 与页面显示同一种子。
- 完整测试不得访问小红书或任何外部网络。
