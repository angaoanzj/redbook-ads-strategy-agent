# 真实数据、公开资料与 Mock 分层分析设计

## 目标

使用本地知识库中的 205 条小红书公开笔记完成可计算分析；缺少的行业信息优先引用公开资料，仍无法取得的指标使用情景模拟数据补足，使六个决策模块可以完整展示，同时避免把模拟结果误报为真实事实。

## 数据优先级

系统按以下顺序为每个字段选取数据，低优先级数据不得覆盖高优先级数据：

1. `真实样本`：本地知识库、用户导入的品牌后台数据或用户提供的证据。
2. `公开资料`：官方帮助中心、官方行业材料，以及可核验的第三方原始网页。搜索引擎只用于发现来源，不能作为最终来源。
3. `模拟数据（Mock）`：前两层都没有该字段时生成的演示性情景数据。

## 分析范围

### 真实样本计算

- 笔记发布量与互动量趋势。
- 发布时间代理高峰、标签频次、内容形式表现。
- 关键词主题聚类、爆款共性、卖点覆盖与内容空白。
- 竞品候选只能依据真实笔记中的品牌提及和独立作者数量识别。

### 公开资料补充

- 聚光产品与推广目标说明。
- 平台广告审核和内容风险规则。
- 可以确认来源、发布日期和适用范围的行业趋势。
- CPC、CPM 等行业数字只有在原始来源明确披露口径时才作为公开资料；营销转载或无口径数字不升级为真实基准。

### Mock 补充

- CPC、CPM、转化成本的低／中／高情景值。
- 搜索与信息流预算占比测试方案。
- 竞品定向、预算范围和投放时长的验证假设。
- 缺少后台数据时的投放节奏、止损线和敏感性分析。

不得用 Mock 生成或声称存在具体评论原文、真实成交订单、真实聚光账户、真实竞品定向、已确认广告笔记或具名达人历史业绩。

## 数据标识契约

所有进入报告的指标或结论必须携带：

```json
{
  "data_type": "真实样本 | 公开资料 | 模拟数据（Mock）",
  "is_mock": false,
  "source_name": "来源名称",
  "source_url": null,
  "as_of": "2026-07-24",
  "evidence_grade": "A | B | C | M",
  "mock_basis": null,
  "warning": null
}
```

Mock 项必须满足：

- `data_type = "模拟数据（Mock）"`。
- `is_mock = true`。
- `evidence_grade = "M"`。
- `mock_basis` 解释模拟区间或公式。
- `warning = "仅用于方案演示和敏感性分析，不代表真实平台、竞品或账户数据。"`。

前端在数值、表格行和决策结论旁显示醒目的 `模拟数据（Mock）` 标签，不能只在报告底部统一声明。

## 决策生成规则

- 真实样本结论使用肯定但有限定范围的表述，例如“205 条搜索样本内”。
- 公开资料结论注明来源、发布日期和适用范围。
- Mock 结论使用“情景假设”“建议测试”而不是“行业平均”“竞品正在投放”等事实语气。
- 同一模块可以同时展示三类数据，但汇总可信度只计算真实样本和公开资料。
- 当真实数据随后导入时，系统按字段自动替换对应 Mock，并保留来源追踪信息。

## 页面与接口

- 分析表单增加“允许使用 Mock 补足缺失指标”开关，默认开启以满足本次演示需求。
- `/analyze` 接收 `allow_mock`；知识库查询真实笔记时仍排除 Mock 笔记。
- 模块 1、3、4、5、6 的可计算部分使用真实样本；模块 1 的聚光大盘及竞品投放未知字段按上述规则补足。
- 页面所有字段名、标签、警告和数据来源使用中文。
- JSON 与 Markdown 下载保留完整的数据类型和来源元数据。

## 错误与降级

- 公开网页不可访问时保留来源候选但不写成已验证事实。
- Mock 生成失败时保留数据缺口，不用空值伪装成零。
- 对来源日期、单位或统计口径不完整的公开数字降级为参考资料，不进入预算公式。

## 测试与验收

- 205 条真实笔记仍被标识为真实样本，且 Mock 不进入笔记趋势统计。
- 缺失投放指标启用 Mock 后有完整情景值，并逐项显示 Mock 标签。
- 关闭 Mock 后恢复为空值和数据缺口提示。
- 导入真实投放指标后，同字段不再返回 Mock。
- 不生成具名虚假达人、评论、订单、广告证据或竞品投放事实。
- API、网页和导出报告中的数据类型与来源一致。
