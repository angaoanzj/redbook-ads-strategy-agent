# 作业目标 Agent 对照表

对照「小红书投放策略决策 AI Agent」作业要求与当前 `xiaohongshu-strategy-agent` 实现。

## 必做六大模块

| 模块 | 作业要求要点 | 当前状态 | 差距／备注 |
| --- | --- | --- | --- |
| 1 赛道与竞品 | 自然大盘、聚光大盘、竞品拆解、风险预警 | **已实现** | 竞品投流识别依赖广告标识人工核验；预算/定向多为假设或 Mock |
| 2 用户画像 | 三维画像、3 方向双评分、15 选题、投流筛选标准 | **基本实现** | 画像标签可直接用于聚光测试；评分仍偏模板，需账户数据校准 |
| 3 关键词与达人 | 双轨词库、达人分层、20 人名单 | **已实现（护栏更严）** | 无 CSV 时不编造名单；满额 20 人需足够导入；无蒲公英 API |
| 4 聚光前置决策 | 账户结构、定向包、出价节奏、搜推联动、效果预估与 5 SOP | **已实现** | ROI/CVR 依赖演示基准时须标注待替换 |
| 5 全域预算节奏 | 自然/聚光拆分、预热爆发长尾、协同与应急 | **已实现** | 比例确定性计算；可选 LLM Agent 批注 |
| 6 关键词策略 | 三级词库、布局、热搜监控 | **部分实现** | 热搜为人工粘贴评分，非官方实时 API |

## 诚实边界（人工仍须拍板）

1. 不伪造实时平台热搜、未标识广告的「竞品正在投流」、由互动反推的竞品预算。
2. 图片/视频审核未接视觉模型前只返回 `pending_*`，不算已完成多模态审核。
3. 探测预算 ≠ 全案聚光预算；达人下单前必须人工复核。
4. `use_agent_modules` 失败时回退确定性引擎，报告仍可执行。
